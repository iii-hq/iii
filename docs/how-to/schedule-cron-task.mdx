<Note>
  In 0.25 the cron worker still publishes the `cron` trigger type, so you bind a function to a
  schedule with `registerTrigger({ type: "cron", function_id, config: { expression } })`.
  `registerTrigger` is deprecated and logs one warning per process. From cron 0.21.27 you can
  instead observe `cron::on-tick` with `{ expression }` as its args. 0.26 removes `registerTrigger`,
  so move your schedules to [observers](../using-iii/observers) before or with that upgrade; see
  [Upgrading from 0.24.x](../upgrading/from-0-24-x#providers-not-migrated-yet).
</Note>
