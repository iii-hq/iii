---

<Note>
  `condition_function_id` belongs to the trigger APIs, which are deprecated in 0.25 and keep working.
  Observers offer declarative [filters](../reference/filters) for conditions you can state over the
  event, evaluated without an extra function call. A condition that needs code (a lookup, an auth
  check) has no filter form: keep `condition_function_id`, or move the check into the target
  function. See [Gate a trigger with a
  condition](../using-iii/triggers#gate-a-trigger-with-a-condition) for the trigger form and
  [Observers](../using-iii/observers#filters) for the filter form.
</Note>
