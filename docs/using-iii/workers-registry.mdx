The [iii Worker Registry](https://workers.iii.dev/) indexes immutable worker versions. Each version
resolves to a normalized `package_descriptor`, its SHA-256 digest, and digest-addressed artifacts.

## Install a Registry package

`iii worker add` accepts only a Registry reference:

```bash
iii worker add state@next
iii worker add state@0.22.2
```

The resolver verifies the descriptor digest, records the descriptor and immutable artifact source
in `iii.lock`, installs the artifact, and starts it. It never accepts a local path or an arbitrary
OCI reference.

Use `iii worker sync --frozen` to replay and verify a committed lock without selecting a newer
version. Use `iii worker reinstall <registry-ref>` to redownload the same immutable package.

## Use a package in Compose

For a project stack, declare the Registry reference in the root `worker-compose.yaml`:

```yaml
workers: {}
stacks:
  default:
    namespace: dev
    containers:
      state:
        worker: package://state@next
```

Validate and start the stack:

```bash
iii compose validate --file worker-compose.yaml
iii compose --up --file worker-compose.yaml
```

Local source is a different flow: declare it under the root `workers` catalog and reference it as
`catalog://<slug>` from a stack.
