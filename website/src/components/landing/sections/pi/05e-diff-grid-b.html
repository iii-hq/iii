same contract, both sides of the house.

app teams register functions and declare triggers, focused on business logic. platform teams publish workers, focused on the capability. both sides fulfill the same contract: no bespoke SDKs, no internal client libraries.

pi is shaped for one developer at a time. iii is shaped for a team.

orders::create
platform worker and app worker, same shape
 // platform team, inside the http worker
worker.registerTrigger({
  type: "http",
  function_id: "orders::create",
  config: { api_path: "/orders", http_method: "POST" },
})

 // app team, in their own worker, same shape
worker.registerFunction("orders::create", async (payload) => {
  return { status_code: 201, body: await createOrder(payload.body) }
})
