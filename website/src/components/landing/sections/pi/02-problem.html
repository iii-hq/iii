customizing your agent doesn't shrink the system it's building.
it still has to integrate with everything already in your stack.

most of what a coding agent writes on a real project is integration code: auth boilerplate, retry logic, schema translation, glue between services. on a real system that's easily 80% of the diff.

every line of it is tokens spent, context loaded, and a new place to be wrong, for the agent and for the human reading its output.

a better prompt, a bigger context window, a sharper harness makes the agent better at writing that glue. none of it makes the glue go away. the complexity lives in the system, not the harness, so the harness is not where you fix it.
