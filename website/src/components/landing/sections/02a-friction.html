§ 01 · THE FRICTION

iii is a system for developing software.
it removes the friction between the pairs that pull against each other in every stack.

  • developmentproduction
  • integrationuse
  • architectureextensibility
§ 02 · WHAT IT PROVIDES

iii does this by being all of these at once.
each one is the same three primitives seen from a new angle.

01

a protocol

one wire format that every language and every service already speaks.

02

a small set of primitives

worker, trigger, function. everything else is a composition of the three.

03

a worker orchestrator

starts, supervises, and restarts every process that connects.

04

a registry

iii worker add stripe. a capability installs like a package.

05

a compose file, and a swarm

declare the system once, run it on one machine or on a hundred.

06

an agentic development environment

agents read a live system's functions and triggers instead of guessing at them.

07

a self-extensible application

a running system gains capability without being redesigned.

§ 03 · THE RESULT

everything stays live.
the system you build is the system you run, and it never stops answering for itself.

  • live composability any function calls any other function, in any language, on any machine.
  • live extensibility add a worker to a running system without redesigning the architecture.
  • live discoverability what one worker exposes becomes visible across the system in real time.
  • live observability operations, traces, and behavior across the whole connected stack.
