worker, trigger, function. three primitives instead of a framework per feature. small enough to hold in one context window, big enough to run a whole system.

an agent that can only read, write, and run a shell command is a system of one. the database, the queue, the cron job, the other team's service, all of it sits outside, reachable only through code the agent has to write from scratch, every time.

on iii the agent is a worker like any other. it calls the same registry the system does, so its tools, its memory, and its orchestration are the same three primitives everything else on the engine already speaks.
