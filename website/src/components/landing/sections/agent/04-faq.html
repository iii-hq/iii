questions. the ones people ask before their first worker.

how big is it?+

base iii is 50MB (linux, x86, v0.22.0) for an entire production-capable system, harness included. no external dependencies, no extra upkeep. install it and it's already running.

is this MCP?+

no. functions with live, published schemas are the contract, and one protocol replaces a per-tool server for each integration. it's software that works, not a config file pointed at a vibe.

do i lose my model choice, or my keys?+

no. model calls route through the llm-router worker on the engine, so adding a provider or a model is a router config, not an agent rewrite. your keys stay in your engine's configuration, not in the agent process.

can i still write extensions?+

yes. add a worker and it becomes callable by everything else already running, in any language, with no reload.

what if the engine dies?+

triggers are durable and replay. workers reconnect and re-register invisibly. nothing you built has to notice.

vendor lock-in?+

open protocol, open engine, you own your workers. moving a workload off iii is a redeploy of the workers you wrote, not a rewrite.
