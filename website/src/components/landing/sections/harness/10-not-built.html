what we didn't build. and why the system is better for it.

no MCP

functions with live, published schemas are the contract. one protocol replaces a per-tool server for each integration.

no sub-agent framework

an agent is already a worker. spawn another, or react on a trigger — orchestration is the runtime, not a feature.

no permission popups

policy is a worker concern. gate by function allow-list, run in a sandbox worker, or build your own flow.

no plan mode

write the plan to state, let a trigger drive each step. plans are data the system acts on, not a UI mode.

no built-in to-dos

a to-do is a state key and a cron trigger. compose it from the primitives instead of waiting for the feature.

no background bash

a long-running task is a worker with a durable trigger. it outlives the turn on purpose, not by accident of a shell.
